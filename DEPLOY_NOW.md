## ⚡ Quick Deploy Steps (5 Minutes)

### Step 1: Commit and Push All Files
Open Git Bash or Command Prompt in your project folder:

```bash
git add .
git commit -m "Add deployment files and photo management"
git push origin master
```

### Step 2: Enable GitHub Pages
1. Go to: https://github.com/Mrobii/JoshuaEvent-s/settings/pages
2. Under **"Source"**, select: **"GitHub Actions"**
3. Click **Save**

### Step 3: Trigger Deployment
The GitHub Action will automatically run when you push!

**Or manually trigger it:**
1. Go to: https://github.com/Mrobii/JoshuaEvent-s/actions
2. Click on **"Deploy Joshua Events to GitHub Pages"** workflow
3. Click **"Run workflow"** → **"Run workflow"** button

### Step 4: Wait 2-3 Minutes
Watch the build progress at:
https://github.com/Mrobii/JoshuaEvent-s/actions

✅ When you see a **green checkmark**, your site is live!

## 🔧 Troubleshooting

### If the page is blank:
1. Wait 5 minutes (first deployment can take time)
2. Clear browser cache (Ctrl + Shift + Delete)
3. Try in incognito/private window

### If images don't show:
- Upload them via the Add Photos page after deployment
- Or import your previously exported JSON file
